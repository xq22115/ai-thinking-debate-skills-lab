## Debate consensus

1. **30 is a pool, not fixed fan-out.** Activate roles by information gain/risk.
2. **Diversity beats duplication.** Same prompt ×30 is not epistemic diversity.
3. **Retain minority hypotheses.** Do not majority-vote away strong dissent.
4. **Selective sharing beats full broadcast.** Share decisive evidence and disagreement.
5. **Evidence beats popularity.** Reproducible tests/primary evidence outrank confidence.
6. **Externalize durable state.** Use task IDs, checkpoints, resumable state.
7. **Skills must be composable/versioned/testable.**
8. **Compatibility must be explicit.** Host/version/OS/tool/fallback adapter.
9. **No fake completion.** Implemented ≠ tested ≠ host-live ≠ deployed ≠ healthy.
10. **Root cause before patch chains.** Repair common mechanism, regression-test cluster.

## Dynamic topology

`INTAKE → independent framers → evidence retrieval → 3–7 hypothesis roles → red team/falsifier → selective cross-sharing → evaluator → integrator → execution → verification → completion gate → checkpoint/archive`

Escalate toward 30 roles only when uncertainty, breadth, impact, or contradictions justify it.
