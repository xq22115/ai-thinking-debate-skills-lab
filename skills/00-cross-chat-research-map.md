# Cross-Chat Research Map

## Classification
- `RECOVERED`: prior-chat evidence.
- `CURRENT-VERIFIED`: checked against 2026 primary/current sources.
- `HOST-LIVE-UNVERIFIED`: package/config existence may be known, but live activation is not proven.

## Continuous thinking / long-horizon execution
Recurring failures recovered across chats: 秒回, checkpoint loss, weak naming, false completion, A→B→C regression chains, context/state confusion, desktop/web divergence, guessed paths/config.

Recovered design responses: task ledger, explicit state machine, evidence-gap queue, reversible checkpoints, independent candidate fixes, rollback, completion receipts, recovery after interruption, root-cause clustering.

2026 correction: long thinking must be implemented as external durable state + resumable execution, not only a prompt asking the model to keep thinking.

## Multi-agent debate
Recovered direction: 5–10, 10+, then 30-role debate; include red team, contradiction search, source audit, compatibility audit, adjudication.

2026 correction: use a role pool rather than N homogeneous clones. Prefer independent hypotheses, specialized critique, selective disagreement sharing, and evidence adjudication.

## Truth / evidence governance
Stable recovered principles:
- FACT / INFERENCE / ASSUMPTION separation;
- evidence-to-claim binding;
- current primary sources first;
- counterexample search;
- no terminal `cannot` without capability challenge;
- no terminal `done` without acceptance evidence;
- preserve conflicts;
- stale-evidence invalidation;
- reversible execution;
- explicit unknowns.

## Skills
Recovered goal: downloadable reusable skill packs rather than giant one-off prompts.

Core families: deep thinking, debate, root-cause, evidence-gap research, adaptive routing, completion gate, recoverable state, Socratic/dialogue, legal, animation/media, desktop compatibility.

2026 correction: package small skill folders with metadata, scope, instructions, compatibility, tests/evals, security review, provenance.

## OpenClaw / desktop agent OS
Recovered architecture: Gateway + browser/tools + cron/webhooks + skills/plugins + memory + subagents/ACP + multi-device runners; deterministic side effects should be separated from probabilistic reasoning/orchestration.
