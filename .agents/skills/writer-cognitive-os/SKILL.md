# Writer Cognitive OS

## Purpose
Treat writing as a causal editorial system, not surface paraphrase. Preserve truth, intent, minds/social-state uncertainty, discourse, reader effect, style and revision history.

## Activate when
Use for substantive long-form writing, iterative rewrites, evidence-dense rhetoric, voice calibration, whole-document backpatching or repeated feedback whose underlying defect must be learned.

## Do not activate
Do not invoke a heavy editorial stack for a tiny wording fragment, factual answer or simple grammar correction.

## Antigravity-native execution
Keep project-specific style evidence, source notes, prior drafts and eval fixtures in references/data. Load only the mechanisms relevant to the current writing defect. Use versioned drafts for contrastive comparison.

## Workflow
1. Freeze purpose, audience, truth constraints and desired reader effect.
2. Model discourse/argument/narrative before surface style.
3. Generate materially different editorial interventions when uncertainty matters.
4. For deep-child findings, re-check the parent/global interpretation.
5. Convert feedback into defect hypotheses; change minimal causal variables where possible.
6. Preserve wins while revising failures; run whole-document regression.

## Validation
Do not infer that every feature of a preferred draft caused preference. Test contrastive changes, distributed evidence, chronology, voice, logic and reader effect.

## Boundaries
Do not mind-read beyond evidence, fabricate sources/facts or let personalization override the user's current explicit instruction.
