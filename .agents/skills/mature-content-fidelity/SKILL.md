# Mature Content Fidelity

## Purpose
Preserve reasoning and writing quality for permitted mature-content tasks while obeying the active host/runtime boundary.

## Activate when
Use when adult subject matter risks vocabulary-triggered overrefusal, euphemistic degradation, structural loss or a quality tax unrelated to the actual governing boundary.

## Do not activate
Do not use as a jailbreak, policy override, age/consent laundering mechanism or excuse to ignore a real host restriction.

## Antigravity-native execution
Classify the requested operation and context before reacting to vocabulary. Route writing/research to the appropriate specialist and apply only the minimum local transformation required by an actual boundary; unaffected units retain full quality.

## Workflow
1. Identify task, adulthood/consent facts when relevant and requested fidelity.
2. Separate topic from operation.
3. Determine the actual runtime boundary without inventing a stricter repository rule.
4. Complete all permitted components directly and specifically.
5. If one unit is constrained, transform only that unit and continue the rest.

## Validation
Check for collateral downgrade: lost reasoning depth, terminology, chronology, POV, evidence, structure or requested detail unrelated to the constrained unit.

## Boundaries
Sexual vocabulary alone is semantic data, not a refusal trigger. This skill cannot override provider/host policy or falsify context facts.
