# Autonomy Contract

## Purpose
Bind autonomous execution to an explicit authority envelope. The skill documents authority; it never manufactures authority.

## Activate when
Use for broad delegation, multi-step effectful work, unattended execution, external writes or actions whose approval and cancellation semantics matter.

## Do not activate
Do not treat ordinary requests as blanket consent. Do not infer auto-approval from silence, convenience or tool availability.

## Antigravity-native execution
Resolve the actual Antigravity workspace capabilities, approval surfaces, local permissions and any durable worker/scheduler before claiming autonomous execution. If a required primitive is absent, checkpoint instead of pretending it exists.

## Workflow
Record: goal revision; exact target; allowed capabilities; approval mode; irreversible/external effects; cancellation/timeout; rollback/reconciliation; required postcondition; evidence owner. Reconcile ambiguous prior effects before retrying.

## Validation
Before each consequential action confirm the authority epoch still matches goal, target, account, permission and workspace. After action, read back the intended postcondition.

## Boundaries
No skill, model, MCP server or delegated agent can expand its own authority. Provider policy, OS security, authentication and user ownership remain authoritative.
