## Host-specific removals/replacements

No canonical skill assumes another product's private tool names, memory APIs, plugin manifests, approval semantics, sandbox, background workers or connector namespaces. Those mechanisms are replaced by capability detection plus Antigravity workspace/file/terminal/MCP primitives that are actually visible and authorized.
