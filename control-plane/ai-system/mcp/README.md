# MCP Integrations

Track MCP integrations here without storing credentials.

For each MCP integration, record:
- server/project name
- canonical source
- transport/runtime
- required permissions
- configuration example with placeholders only
- capabilities exposed
- health check
- rollback/disable procedure
- status: `active`, `experimental`, `disabled`, or `blocked`

Treat an MCP as active only after its consumer can successfully list/call the expected tools and the result is verified.
