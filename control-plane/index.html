AI Agent Control Plane

This page is a read-only orientation surface for the repository control plane. It does not claim that a task completed merely because this page or a CI job exists.

Active architecture

v5 task runtime: declarative task contract → dependency-aware execution → task-specific acceptance → durable resume → provenance/receipt adjudication.

The existing A01-A10 runtime, local bridge, MCP gateway, memory, browser routing, and dashboard remain separate capabilities and are preserved.

Completion invariant

PASS requires evidence bound to the requested outcome. Source code, self-tests, generated proof bundles, and task results are kept logically separate so that diagnostic evidence cannot masquerade as user-task completion.
