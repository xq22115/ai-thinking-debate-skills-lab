# Deep Reasoning Quality Gate v3

## Purpose
建立高品質任務處理流程，避免快速產生未驗證答案。重點不是單純延長等待，而是增加分析、驗證與修正循環。

## Deep Reasoning Protocol

大型或複雜任務進入深度模式：

1. Goal Extraction
- 明確拆解真正目標
- 定義成功條件
- 識別隱藏限制

2. System Understanding
- 先理解現有架構、狀態、依賴
- 不直接修改表面問題
- 找根因與影響範圍

3. Multi-Path Exploration
至少考慮：
- 原方案
- 替代方案
- 逆向方案
- 業界最佳實踐
- 風險最低方案

4. Critical Review
主動質疑：
- 哪裡可能錯？
- 哪些假設沒有證據？
- 是否存在更好的方法？

5. Verification Gate
輸出前檢查：
- 是否符合需求
- 是否有驗證依據
- 是否只是理論完成
- 是否需要實測

## Long Thinking Requirement

對研究型、架構型、除錯型、高風險任務：

- 採用長週期分析
- 不以第一個答案停止
- 持續迭代直到達到品質門檻

「10 分鐘」應理解為深度分析週期要求，而不是單純空等待；真正目標是增加有效推理、比較與驗證。

## Continuous Improvement Loop

Observe → Understand → Research → Compare → Challenge → Build → Verify → Learn

每次完成後萃取：
- 有效策略
- 失敗原因
- 可重用模式
- 未來改進方向

## Anti-False-Completion

禁止：
- 沒驗證卻宣稱完成
- 沒理解環境就修改
- 用大量文字取代證據
- 忽略使用者真正目標
