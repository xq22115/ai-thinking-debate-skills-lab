# Source Scope

## Included
- retained cross-chat summaries,
- prior assistant outputs recoverable through personal context,
- persistent project/version memories,
- current-session GitHub connector observations.

## Not included
- a byte-for-byte export of all historical conversations,
- deleted/unavailable chats,
- artifacts whose raw files were not retrievable in this session,
- independent 2026-08-18 web re-validation of every historical tool/version claim.

## Why this matters
This archive is designed as a research ledger, not as proof that every prior statement was correct. Any item tagged `ARCHIVAL_CLAIM` should be verified against primary sources before being used as present-day setup instructions.
