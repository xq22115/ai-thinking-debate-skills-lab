## Preservation rule
A named version in this catalog means “this project/version appeared in cross-chat research.” It does **not** by itself prove:
- code is still available,
- package hash is known,
- tests can be reproduced,
- current compatibility,
- account-level deployment,
- live-model behavior improvement.
